# Sistem Perpustakaan Sederhana (Python OOP)

Project UTS Pemrograman Berorientasi Objek — Ilmu Komputer 3B-Kom, Universitas Bina Bangsa. Aplikasi perpustakaan berbasis terminal (tanpa GUI/database) untuk mengelola buku, peminjaman, pengembalian, dan denda.

## Konsep OOP yang Digunakan
- Class dan Object (Buku, Anggota)
- Constructor `__init__()`
- Attribute dan Method
- Encapsulation (atribut private)
- Property dan Setter
- Class Method
- Static Method

## Cara Menjalankan
python Sistem_perpustakaan.py
